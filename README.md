# Atlas · versión web

Versión web de Atlas, la app de rutinas de gimnasio: https://05markii.github.io/atlas-web/

En iPhone, ábrela en Safari y toca Compartir › «Añadir a pantalla de inicio». Así se abre a pantalla completa, funciona
sin conexión y los entrenos se guardan en el móvil.

Aquí solo está la web ya compilada (`npm run build:web`), sin las fotos de los catálogos de las marcas.
